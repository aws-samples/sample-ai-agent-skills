# AWS Well-Architected Tool Diagnostics Skill

Agent skill for investigating and troubleshooting AWS Well-Architected Tool problems using structured runbooks.

---

## What This Skill Covers

Structured troubleshooting for AWS Well-Architected Tool — workload reviews, lens selection, improvement plans, milestones, custom lenses, and sharing.

### Activate When

- Workload review issues
- Lens configuration problems
- Improvement plan errors
- Milestone creation failures
- Custom lens issues
- Sharing or cross-account problems

---

## Prerequisites

- AWS CLI v2 with wellarchitected, IAM permissions
- AWS Organizations for cross-account sharing
