# Amazon Q Developer Diagnostics Skill

Agent skill for investigating and troubleshooting Amazon Q Developer problems using structured runbooks, anti-hallucination guardrails, and systematic investigation workflows.

---

## What This Skill Covers

Structured troubleshooting for Amazon Q Developer — code suggestions, security scanning, code transformation, IDE integration, customization, and billing.

### Activate When

- Code suggestions not appearing or poor quality
- Security scan failures or unexpected results
- Code transformation errors
- IDE plugin installation or connection issues
- Customization training failures
- Billing or usage tier questions

---

## Prerequisites

- IDE with Amazon Q Developer plugin installed
- AWS Builder ID or IAM Identity Center authentication
- AWS CLI v2 for administrative operations
