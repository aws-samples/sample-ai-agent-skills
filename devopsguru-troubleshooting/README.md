# Amazon DevOps Guru Diagnostics Skill

Agent skill for investigating and troubleshooting Amazon DevOps Guru problems using structured runbooks, anti-hallucination guardrails, and systematic investigation workflows.

---

## What This Skill Covers

Structured troubleshooting for Amazon DevOps Guru — insights, anomaly detection, resource coverage, notification channels, cost estimation, and proactive insights.

### Activate When

- Missing or delayed insights
- False positive anomalies
- Resource coverage gaps
- Notification delivery failures
- Cost estimation questions
- Proactive insight configuration

---

## Prerequisites

- AWS CLI v2 with devops-guru, CloudWatch, SNS, IAM permissions
- Resources monitored via CloudFormation stacks or tags
