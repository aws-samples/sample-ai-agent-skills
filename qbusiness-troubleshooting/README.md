# Amazon Q Business Diagnostics Skill

Agent skill for investigating and troubleshooting Amazon Q Business problems using structured runbooks, anti-hallucination guardrails, and systematic investigation workflows.

---

## What This Skill Covers

Structured troubleshooting for Amazon Q Business — application creation, data source connectors, retrieval quality, guardrails, plugins, web experience, and IAM Identity Center integration.

### Activate When

- Application creation or configuration failures
- Data source connector sync errors
- Poor retrieval quality or missing answers
- Guardrails blocking legitimate queries
- Plugin creation or execution errors
- Web experience access or display issues
- IAM Identity Center integration problems

---

## Prerequisites

- AWS CLI v2 with qbusiness, S3, IAM, SSO, CloudWatch permissions
- IAM Identity Center configured in the account
