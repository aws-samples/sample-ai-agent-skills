# AWS AppConfig Troubleshooting Skill

Diagnose and resolve AWS AppConfig issues including configuration deployments, feature flags, validation errors, deployment strategies, extensions, and integration with Lambda/ECS/EC2.

## Runbooks

| ID | Title | Severity |
|----|-------|----------|
| A1 | Application Creation Failures | MEDIUM |
| A2 | Environment Configuration Issues | MEDIUM |
| B1 | Configuration Profile Errors | HIGH |
| B2 | Validation Failures | HIGH |
| C1 | Deployment Failures | CRITICAL |
| C2 | Deployment Strategy Issues | HIGH |
| C3 | Rollback Triggers | HIGH |
| D1 | Feature Flag Configuration | MEDIUM |
| D2 | Feature Flag Toggle Issues | HIGH |
| E1 | Extension Failures | MEDIUM |
| E2 | Extension Association Issues | MEDIUM |
| F1 | Lambda Extension Integration | HIGH |
| F2 | ECS Agent Integration | HIGH |
| Z1 | General Troubleshooting | MEDIUM |

## Usage

Upload `appconfig-troubleshooting.zip` to the AWS DevOps Agent via Settings → Add Skill → Upload Skill.
