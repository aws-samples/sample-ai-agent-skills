# AWS Compute Optimizer Diagnostics Skill

Agent skill for investigating and troubleshooting AWS Compute Optimizer problems using structured runbooks.

---

## What This Skill Covers

Structured troubleshooting for AWS Compute Optimizer — EC2, Lambda, EBS, ECS recommendations, enrollment, and export.

### Activate When

- Missing or incorrect recommendations
- Enrollment or opt-in issues
- Export job failures
- Recommendation interpretation questions

---

## Prerequisites

- AWS CLI v2 with compute-optimizer, EC2, Lambda, ECS, S3, IAM permissions
- Account enrolled in Compute Optimizer
